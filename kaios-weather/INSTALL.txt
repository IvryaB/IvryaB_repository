ПОГОДА для KaiOS — установка по USB через Pale Moon (WebIDE)
=============================================================

В архиве:
  weather-kaios/        — папка приложения (её открывают в WebIDE)
  weather-omnisd.zip    — тот же пакет для установки через OmniSD / Wallace Toolbox
  УСТАНОВКА.txt         — эта инструкция

Подходит для KaiOS 2.5 (Nokia 8110/2720, Sigma S3500 sKai и др.).

1. Включить отладку на телефоне
   - Наберите на клавиатуре:  *#*#33284#*#*
     (в строке состояния появится значок «жучка»).
   - Если код не срабатывает: Настройки → Устройство → Режим разработчика / Debugger → «ADB and DevTools».

2. Подготовить компьютер
   - Установите ADB (Android platform-tools).
   - Подключите телефон по USB и выполните в командной строке:
         adb devices
     Телефон должен появиться в списке (если «unauthorized» — разрешите на телефоне).
   - Пробросьте порт отладчика:
         adb forward tcp:6000 localfilesystem:/data/local/debugger-socket

3. Установить через Pale Moon
   - Распакуйте этот архив в любую папку.
   - Pale Moon → меню «Инструменты» → «Веб-разработка» → WebIDE.
   - Справа: «Remote Runtime» → адрес localhost:6000 → OK.
     (Если телефон спросит разрешение на подключение — подтвердите.)
   - Слева: «Open Packaged App» → выберите папку weather-kaios
     (ту, в которой лежит manifest.webapp).
   - Нажмите треугольник «Install and Run» вверху. Приложение «Погода» появится в меню телефона.

   Если в вашей сборке Pale Moon нет WebIDE, подойдёт тот же порядок в Firefox 59 / Waterfox Classic,
   либо установите weather-omnisd.zip через OmniSD (файл кладётся в папку apps на карте памяти).

4. Первый запуск
   - Разрешите доступ к местоположению — погода покажется для «Моё местоположение».
   - Левая клавиша — города (добавить, «Опции» → «Сделать основным»).
   - Правая клавиша — настройки: автообновление, уведомления, единицы, язык.
   - Обновить погоду вручную: центральная клавиша или «0» в любом месте экрана.
   - Уведомления: Настройки → Уведомления → Вкл, выберите режим
     («Каждые N часов» с окном «С/До» или «В заданное время» до 4 раз в день) и «Повтор».
     «Отправить сейчас» — проверка, что уведомления приходят.
     Время можно набирать цифрами: например 0730.

Погода: Open-Meteo (бесплатно, без ключа). Названия мест: OpenStreetMap.
После проверки отладку можно выключить тем же кодом *#*#33284#*#*.
